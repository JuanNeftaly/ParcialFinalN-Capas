# Sistema de Soporte Técnico (Spring Security + JWT)

Bienvenidos a la documentación del **Parcial Final de Programación N-Capas**

Este proyecto simula un sistema donde los usuarios pueden crear solicitudes de soporte (tickets) y los técnicos pueden gestionarlas. El objetivo principal es agregar autenticación y autorización utilizando Spring Security + JWT, y contenerizar la aplicación con Docker.

!!! note "Nota Importante sobre el Proyecto"
    El proyecto ya tiene una estructura básica de Spring Boot con endpoints funcionales para manejar tickets. No es necesario modificar la lógica de negocio, solo agregar seguridad. Además, se incluye una colección de Postman para probar los endpoints.

Para conocer cómo se implementó la seguridad y los permisos, visita la sección de [Desarrollo y Roles](desarrollo.md)
